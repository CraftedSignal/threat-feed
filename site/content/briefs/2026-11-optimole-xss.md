The Optimole - Optimize Images | Convert WebP & AVIF | CDN & Lazy Load | Image Optimization plugin for WordPress is vulnerable to Stored Cross-Site Scripting (XSS) via the 'comment' parameter in all versions up to, and including, 4.2.17. The vulnerability exists because the plugin fails to sanitize input and improperly handles output escaping. 

The exploit bypasses standard WordPress comment filters by storing payloads that do not contain HTML metacharacters at the time of entry; the characters are instead generated by the plugin's own decoder during rendering. Successful exploitation requires the plugin to be configured with a valid CDN key/secret and the image replacer enabled, which is the default configuration post-setup.

## Impact

Successful exploitation allows unauthenticated attackers to inject arbitrary web scripts into pages. These scripts execute in the context of any user who accesses an injected page, potentially leading to session hijacking, unauthorized actions, or further compromise of the victim's session.

## Recommendation

- Update the Optimole plugin to the latest version beyond 4.2.17 once a patch is available.
- Review plugin configuration settings to ensure unnecessary features such as 'image replacer' are disabled if not required for site functionality.
- Implement a Content Security Policy (CSP) to mitigate the impact of XSS vulnerabilities by restricting the execution of unauthorized scripts.
- Audit WordPress comment sections for anomalous script content if the site is suspected of being targeted.
