A critical prototype pollution vulnerability (CVE-2026-33696) exists within the GSuiteAdmin node of n8n, a workflow automation platform. This flaw enables an authenticated user, possessing the ability to create or modify workflows, to inject arbitrary values into the `Object.prototype`. By crafting malicious parameters during node configuration, an attacker can effectively overwrite properties of the base JavaScript object.
