The VikRentCar WordPress plugin (up to and including version 1.4.9) fails to properly sanitize the 'poplink' parameter, allowing for Stored Cross-Site Scripting (XSS). An unauthenticated attacker can retrieve the required 'vikwp_nonce' token from the publicly accessible booking-confirmation page and subsequently inject malicious scripts into the application. These scripts execute in the browser of any user who accesses the compromised page.

## Impact
Successful exploitation allows unauthenticated attackers to inject arbitrary web scripts into WordPress pages. This can lead to session hijacking, unauthorized actions performed on behalf of site administrators, or the redirection of visitors to malicious sites.

## Recommendation
- Update the VikRentCar plugin to the latest available version beyond 1.4.9 immediately to remediate the input sanitization flaw.
- Implement a Web Application Firewall (WAF) rule to inspect and block POST requests containing script-like payloads in the 'poplink' parameter.
- Audit the booking-confirmation page logs for repetitive requests that appear to be harvesting 'vikwp_nonce' tokens.
