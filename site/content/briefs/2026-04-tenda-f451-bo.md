A critical buffer overflow vulnerability has been identified in Tenda F451 routers running firmware version 1.0.0.7_cn_svn7958. This flaw resides within the `fromGstDhcpSetSer` function of the `/goform/GstDhcpSetSer` file, part of the `httpd` component. The vulnerability can be triggered remotely by manipulating the `dips` argument. This can allow an attacker to gain unauthorized access and control over the device.
