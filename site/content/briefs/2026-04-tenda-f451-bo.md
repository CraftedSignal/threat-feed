A critical stack-based buffer overflow vulnerability, CVE-2026-6136, affects Tenda F451 router version 1.0.0.7_cn_svn7958. The vulnerability resides within the `frmL7ImForm` function located in the `/goform/L7Im` file. A remote attacker can exploit this flaw by crafting a malicious HTTP request with a specially crafted `page` argument, leading to arbitrary code execution on the device.
