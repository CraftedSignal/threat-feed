A critical stack-based buffer overflow vulnerability, CVE-2026-6136, affects Tenda F451 router version 1.0.0.7_cn_svn7958. The vulnerability resides within the `frmL7ImForm` function located in the `/goform/L7Im` file. A remote attacker can exploit this flaw by crafting a malicious HTTP request with a specially crafted `page` argument, leading to arbitrary code execution on the device. This is a pre-authentication vulnerability, meaning no prior authentication is needed to exploit it. Given the public disclosure of the exploit, it poses a significant risk, especially to home and small business users who may not promptly apply security updates. Successful exploitation can lead to a complete compromise of the router, potentially allowing attackers to intercept network traffic, inject malware, or use the device as part of a botnet.

## Attack Chain

1. The attacker identifies a vulnerable Tenda F451 router with firmware version 1.0.0.7_cn_svn7958 exposed to the internet.
2. The attacker crafts a malicious HTTP GET or POST request targeting the `/goform/L7Im` endpoint.
3. The crafted request includes the `page` argument, which is designed to cause a stack-based buffer overflow in the `frmL7ImForm` function.
4. The router's web server processes the request and passes the attacker-controlled `page` argument to the vulnerable function.
5. The `frmL7ImForm` function copies the `page` argument to a fixed-size buffer on the stack without proper bounds checking.
6. The oversized `page` argument overwrites adjacent memory on the stack, including the return address.
7. When the `frmL7ImForm` function returns, it jumps to the attacker-controlled address, allowing them to execute arbitrary code.
8. The attacker executes shell commands to gain full access to the router.

## Impact

Successful exploitation of CVE-2026-6136 allows a remote attacker to execute arbitrary code on the affected Tenda F451 router. This could lead to complete compromise of the device, allowing the attacker to intercept and manipulate network traffic, inject malicious code into connected devices, or use the router as a node in a botnet. Given the widespread use of these routers in home and small business environments, a large number of devices are potentially vulnerable.

## Recommendation

*   Deploy the Sigma rule "Detect Tenda F451 Buffer Overflow Attempt" to your SIEM to identify attempts to exploit CVE-2026-6136 via malicious HTTP requests to the `/goform/L7Im` endpoint.
*   Inspect web server logs for requests to `/goform/L7Im` with unusually long `page` parameter values as indicated in the "Detect Tenda F451 Buffer Overflow Attempt" Sigma rule.
*   Monitor network traffic for shell commands originating from Tenda F451 routers, which could indicate successful exploitation.
