A critical stack-based buffer overflow vulnerability has been identified in Tenda F451 router firmware version 1.0.0.7. The vulnerability resides in the `fromAddressNat` function within the `/goform/addressNat` component's `httpd` service. An attacker can trigger the overflow by crafting a malicious payload and sending it as the `entrys` argument in a request to the router.
