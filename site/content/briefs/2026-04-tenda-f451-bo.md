A stack-based buffer overflow vulnerability has been identified in Tenda F451 router firmware version 1.0.0.7. The vulnerability resides in the `fromDhcpListClient` function within the `/goform/DhcpListClient` component's httpd service. A remote attacker can exploit this vulnerability by sending a specially crafted HTTP request with a malicious `page` argument. This can lead to arbitrary code execution on the device.
