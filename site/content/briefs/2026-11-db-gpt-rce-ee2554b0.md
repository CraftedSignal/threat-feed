A vulnerability exists in eosphoros-ai DB-GPT versions up to 0.8.2. The issue is located in the exec_module function within the hf_adapter.py file of the HuggingFace Adapter component. By manipulating the trust_remote_code argument, an attacker can trigger the inclusion of functionality from an untrusted control sphere. This attack can be performed remotely. Publicly available exploit material exists for this vulnerability, and the project has not yet responded to an early issue report regarding this problem.
