The SureCart - Ecommerce Made Easy For Selling Physical Products, Digital Downloads, Subscriptions, Donations, & Payments plugin for WordPress is vulnerable to Stored Cross-Site Scripting via the 'comment' parameter in all versions up to, and including, 4.9.4. This allows unauthenticated attackers to inject arbitrary web scripts that execute when a user accesses a page containing the injected comment. Successful execution requires the comment to be visible on a page that loads SureCart's web-component bundle (e.g., a page containing a SureCart Buy Button block) and requires the comment to be auto-approved or approved by a moderator.
