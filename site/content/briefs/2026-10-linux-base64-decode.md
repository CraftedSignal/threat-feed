This detection brief addresses the use of the 'base64 -d' or 'base64 --decode' commands on Linux systems, a technique frequently observed in Living off the Land (LotL) scenarios. Adversaries employ base64 encoding to obfuscate malicious scripts, payloads, or sensitive configuration data, effectively hiding their intent from basic string-based security analysis. By decoding these files on-the-fly during execution, attackers can minimize their footprint and bypass static detection mechanisms. Monitoring for this pattern is critical for identifying potential stage-two payload delivery or the execution of obfuscated command-and-control scripts. Defenders should focus on command-line telemetry to isolate legitimate administrative usage from malicious decoding activity.

## Attack Chain

1. An attacker gains initial access to a Linux endpoint through exploitation or credential abuse.
2. The attacker stages a base64-encoded file or script within a directory like /tmp or /dev/shm.
3. The attacker prepares a command line to decode the payload using the native 'base64' utility.
4. The process is executed, often spawned from a shell (bash/sh) or a remote execution service like SSH.
5. The utility outputs the decoded, plaintext payload directly into a pipe or temporary file.
6. The decoded payload is subsequently executed, either via shell redirection or by invoking an interpreter like 'python' or 'perl'.
7. Final objectives, such as data exfiltration or the establishment of a persistent reverse shell, are initiated.

## Impact

Successful exploitation of obfuscation techniques allows attackers to execute malicious code while remaining undetected by signature-based endpoint protection. This can lead to full system compromise, the theft of sensitive data, or the establishment of long-term unauthorized access within an organization's Linux environment.

## Recommendation

Prioritize the implementation of process-creation logging to identify suspicious command-line usage.
- Enable Sysmon for Linux Event ID 1 to capture granular process execution telemetry including command lines.
- Deploy the provided Sigma rule to detect the specific use of base64 decoding in your security orchestration platform.
- Establish a baseline of normal administrative tasks to reduce false positives generated by legitimate scripts using base64 for data transmission.
