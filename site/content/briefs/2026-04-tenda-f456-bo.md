A critical stack-based buffer overflow vulnerability, identified as CVE-2026-6196, affects Tenda F456 routers running firmware version 1.0.0.5. The vulnerability resides within the 'fromexeCommand' function of the '/goform/exeCommand' file. A remote attacker can exploit this vulnerability by sending a specially crafted request that manipulates the 'cmdinput' argument, leading to arbitrary code execution on the device.
