The Optimole - Optimize Images | Convert WebP & AVIF | CDN & Lazy Load | Image Optimization plugin for WordPress is vulnerable to Stored Cross-Site Scripting (XSS) via the 'comment' parameter in all versions up to, and including, 4.2.18. 

An unauthenticated attacker can inject arbitrary web scripts into pages. Execution occurs when a user accesses an injected page, provided the comment has been approved by an administrator and the post contains an iframe or video element, which triggers the plugin's video lazy loading functionality.

## Impact

Successful exploitation allows for the execution of arbitrary web scripts in the user's browser.
