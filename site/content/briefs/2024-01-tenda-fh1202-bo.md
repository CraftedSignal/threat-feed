A critical stack-based buffer overflow vulnerability, identified as CVE-2026-7034, has been discovered in Tenda FH1202 version 1.2.0.14(408). The vulnerability resides within the `WrlExtraSet` function of the `/goform/WrlExtraSet` component, which is part of the device's `httpd` server. A remote attacker can exploit this vulnerability by crafting a malicious HTTP request that manipulates the `Go` argument, leading to arbitrary code execution on the affected device.
