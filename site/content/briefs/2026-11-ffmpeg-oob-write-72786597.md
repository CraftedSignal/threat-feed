FFmpeg through 9.0.2 contains an out-of-bounds write vulnerability in the v4l2_buffer_swframe_to_buf() function within libavcodec/v4l2_buffers.c. This issue arises because cumulative plane offsets are not validated against the V4L2 buffer length. An attacker can provide crafted video with dimensions or padding that trigger an unsigned wraparound in v4l2_bufref_to_buf(), causing memcpy() to write past the mmaped driver buffer during V4L2 M2M encoding.
