This threat brief identifies file activity involving `scrcons.exe`, the WMI Script Event Consumer, which is associated with WMI persistence techniques. The detection relies on monitoring file events generated by the `C:\WINDOWS\system32\wbem\scrcons.exe` process.

## False Positives
- Dell Power Manager (C:\Program Files\Dell\PowerManager\DpmPowerPlanSetup.exe)
