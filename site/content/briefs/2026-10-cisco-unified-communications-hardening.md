Cisco has conducted an internal security review of multiple Unified Communications products, resulting in software hardening releases that address internally discovered vulnerabilities. These issues are not known to be actively exploited. Cisco has grouped these issues by Common Weakness Enumeration (CWE) and assigned CVE identifiers to each group. No workarounds are available to address these vulnerabilities; software updates are required.
