Falcon (aka XG or Xiàng Gē) is a browser-based command and control framework that compromises browser sessions via malicious JavaScript. Attackers have used the framework to target government entities in one Middle Eastern and four Southeast Asian countries. The framework supports the deployment of malicious Chrome and Firefox extensions that grant full browser control, including access to credentials, session cookies, and network traffic.

## Attack Chain
- **Infection**: Malicious JavaScript is injected directly into webmail and government portals.
- **Execution**: The browser executes an obfuscated JavaScript implant that establishes a persistent WebSocket connection to the C2 server.
- **Persistence**: Persistence is maintained through a three-tier strategy involving browser local storage, cookies, and extension storage.
- **Capabilities**: The framework facilitates data exfiltration (passwords, emails, session cookies), proxy functionality using the victim's browser, and the delivery of the Antino implant.

## Impact
Falcon was used to target ministries of foreign affairs, defense, interior, and law enforcement agencies for strategic intelligence collection.

## Recommendation
Organizations should monitor browser environments for unauthorized extensions and suspicious WebSocket traffic. Conduct analysis of browser-based data exfiltration and ensure rigorous access control for web applications.
