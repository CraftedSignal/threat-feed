The Elastic Defend for Containers integration provides visibility into container runtime threats, including potential container escapes, unauthorized access attempts, and orchestration anomalies. This detection rule serves as an aggregator for the `logs-cloud_defend.alerts-*` index, facilitating triage of alerts generated by the cloud defense module on Linux-based container hosts.

## Impact

Successful exploitation of containerized workloads can lead to unauthorized access to host systems, lateral movement within the container infrastructure, and disruption of containerized services.

## Recommendation

- Deploy the aggregate detection rule to your Elastic Security instance to capture alerts from the `cloud_defend` module.
- Baseline routine activities such as automated CI/CD deployments and scheduled maintenance tasks to create exceptions.
- Implement network segmentation and access controls to restrict exposure of the container orchestration plane.
- Configure alerts to trigger investigation workflows when events are received from `logs-cloud_defend.alerts-*`.
