CVE-2026-32152 is a critical use-after-free vulnerability affecting the Desktop Window Manager (DWM) on Windows systems. Discovered and reported to Microsoft, this flaw allows a locally authenticated attacker to potentially escalate their privileges. The vulnerability stems from improper memory management within DWM, leading to a scenario where an attacker can manipulate memory after it has been freed.
