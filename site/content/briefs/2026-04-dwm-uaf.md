A use-after-free vulnerability, identified as CVE-2026-27924, exists within Microsoft's Desktop Window Manager (DWM). This vulnerability allows a locally authenticated attacker to elevate their privileges on a vulnerable system. The CVE was published on April 14, 2026. Successful exploitation of this flaw could allow an attacker to execute arbitrary code with elevated privileges, potentially leading to full system compromise.
