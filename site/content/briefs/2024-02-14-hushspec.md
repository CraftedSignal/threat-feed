HushSpec is an open specification project designed to create a portable language layer for security policies governing AI agents. The project addresses the issue of security policies being tightly coupled with specific runtime environments, making them difficult to share, reason about, and standardize. HushSpec aims to define a cleaner separation of concerns, focusing on the action boundary of AI agents, including actions such as file access, network egress, shell execution, tool invocation…
