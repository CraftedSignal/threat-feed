Control Web Panel (CWP) before version 1.16 contains a path traversal vulnerability in services/users/index.php. By supplying an unsanitized module name parameter, which is concatenated into an include path, attackers can use directory traversal sequences to include arbitrary local PHP files and execute arbitrary PHP code in the user panel context.
