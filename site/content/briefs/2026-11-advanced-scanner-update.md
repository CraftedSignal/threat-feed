## Overview

The Advanced IP Scanner and Advanced Port Scanner utilities perform update checks via HTTP requests to their respective domains. This activity can be monitored via proxy logs by identifying specific URL structures and query parameters associated with the update check mechanism.

## Attack Chain

- The application triggers an HTTP request to an update server.
- The proxy captures the request, which includes a specific script path and multiple query parameters.

## Impact

Identification of these update checks allows for visibility into the presence and execution of Advanced IP or Port Scanner utilities within the environment.

## Recommendation

Deploy the provided proxy detection rule to identify update check requests generated by these utilities. Investigating these events can assist in baselining or identifying the use of these tools.
